# Reference datasets

Accepted teammate datasets, kept for reference. **These are not pipeline inputs.**

dbt loads only `seeds/`. Our demo data is generated by
`scripts/generate_synthetic_data.py` into `seeds/raw_*.csv` (plus a copy of the raw
records in `data/synthetic/unstructured/`), because the generator is the only thing that
plants the keyless cases, the difficulty tiers, and the hidden `case_id` ground truth that
make the linkage result measurable. Nothing here is read by a model.

| folder | from | contents |
|---|---|---|
| `jim/` | PR #1 (`faker_synthetic_data`) | 6 structured CSVs (1,600 customers, 75 agents, 15 products, CSAT, QA notes, workforce metrics) + 3 unstructured JSON files (11,137 interactions) |
| `francis/` | branch `develop/fsdc-unstructured-data` | 4 NDJSON files, 10,000 records each (chat, email, QA notes, CSAT) |

Francis's files were copied in rather than merged: his branch writes the same four
filenames our generator does, so merging it would have replaced our generated data and the
ground truth the linkage asserts score against.

## What we took from them

The realism in both datasets was analysed and the useful patterns were copied into the
generator as code — identity noise, recontact behaviour, issue composition, operational
value ranges. See **[`docs/realism-report.md`](../../docs/realism-report.md)** for the full
measured analysis, including what was deliberately not copied and why.
